# Continuity and Actual Teaching Outcomes

## Planned continuity

For lesson N, inject:

- approved prerequisites;
- `must_establish` from earlier path lessons;
- next lesson title for closing bridge;
- named anchor/example where intentionally reused.

Do not inject full earlier prose.

## Actual continuity

After teaching, the teacher records:

```text
Established as planned
Partially established
Recovery needed
Not taught
```

Optional:

- unresolved misconceptions;
- anchor actually used;
- short note.

## Next lesson context

```text
Path plan
+ actual status
+ unresolved misconceptions
+ anchor name
```

## Conflict behavior

If plan says prerequisite established but actual says recovery needed:

- show warning;
- suggest repair/retrieval mode;
- do not silently proceed as though mastery occurred;
- teacher may override.

## UI

```text
After teaching

How did this lesson land?

( ) Established as planned
( ) Partially established
( ) Needs recovery
( ) Not taught

Unresolved:
[ ] Oxygen source misconception
[ ] Energy becomes matter

[Save]
```

## Non-goal

This is not learner tracking. It is teacher-confirmed continuity.
