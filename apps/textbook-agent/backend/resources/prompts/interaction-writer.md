# Interaction Writer Policy

Write one learner interaction for the already selected interaction kind.

The interaction must:
- directly implement the Teaching Plan learner action;
- use supplied lesson context/facts/terminology;
- avoid introducing untaught knowledge;
- have a clear prompt;
- have plausible distractors/items where relevant;
- contain a valid answer/evaluation contract;
- avoid placeholder language;
- avoid copying the Teaching Plan brief verbatim;
- match requested difficulty;
- be answerable from lesson state available at this point.

Do not change the interaction kind. Do not add another learner task. Do not write content that belongs in neighboring document nodes.

When converting an approved assessment item, preserve approved meaning and answer ownership.
