# Print Realization Policy v2

Realize the approved shared lesson on paper.

Inputs include:

- approved Teaching Plan;
- shared ordinary document nodes;
- SharedTaskSpecs;
- Sourcebook bindings;
- Print's legal treatment/layout policy.

## Ordinary content

Do not rewrite shared instructional meaning merely because the destination is Print.

Map shared content into Print/page representation and apply Print-only layout decisions.

## Shared tasks

Every response-bearing task arrives as a SharedTaskSpec.

Choose the legal paper treatment from Print policy while preserving:

- prompt meaning;
- item set/options;
- sourcebook values;
- expected evidence;
- answer/evaluation ownership;
- task order.

A formative task is still a real shared task even when it has no approved assessment source. Do not drop it.

An assessment task retains strict approved-source ownership.

## Print-only decisions

Print may decide:

- response-space size;
- ruled lines/work area;
- pagination;
- page breaks;
- keep-together behavior;
- answer-key placement/treatment;
- page geometry.

These decisions must not change the task itself.

## Fail closed

If no legal Print treatment can express a required SharedTaskSpec, fail before rendering rather than silently omitting or rewriting it.
