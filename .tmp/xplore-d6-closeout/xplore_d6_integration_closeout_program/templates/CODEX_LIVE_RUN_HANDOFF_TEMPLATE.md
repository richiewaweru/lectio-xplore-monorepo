# Codex Live Run Handoff

## Preconditions
D6A–D6E PASS.

## Golden browser flow
1. Teacher creates Unit.
2. Generate concepts/path lesson.
3. Generate Print lesson.
4. Complete required review gates.
5. Export/open PDF.
6. Generate Learn lesson.
7. Open Builder.
8. Edit a meaningful field.
9. Reload and confirm persistence.
10. Preview as Student.
11. Publish LearnRelease.
12. Create class/assignment.
13. Open as learner.
14. Complete at least one interaction.
15. Return as teacher.
16. Verify learner activity in progress/analytics.

## Capture
screenshots, timestamps, browser-console errors, backend errors, Unit/PathLesson/generation/release/assignment/instance/attempt IDs, PDF, final PASS/PARTIAL/FAIL.
