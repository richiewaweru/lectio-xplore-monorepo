# Cursor Prompt — C3: Legacy + Dead-Code Removal

Reread all permanent documents first. Then read cleanup state, reachability manifest, and previous report if applicable.

## Objective

Delete everything proven disconnected from the supported product.

Use C0 evidence plus the canonical C1/C2 graph.

Candidates may include old non-Unit generation routes, obsolete studios, v3-era wrappers, compatibility layers, dead planners/skeletons, stale Builder paths, Learn print support, and legacy-only tests/fixtures.

For every deletion record reachability evidence.

PASS only when every DEAD item is removed or explicitly reclassified, no unsupported route is mounted, and Print/Learn regressions remain green.

## Protocol
1. Record starting SHA/branch/dirty state.
2. Inspect actual code.
3. Write a short execution plan.
4. Execute only this phase.
5. Run relevant regressions.
6. Write `docs/cleanup-program/reports/C3/PHASE_REPORT.md`.
7. Update `docs/cleanup-program/CLEANUP_STATE.md` only on PASS.
8. STOP.

If uncertain whether something is dead, reclassify it rather than guessing.
