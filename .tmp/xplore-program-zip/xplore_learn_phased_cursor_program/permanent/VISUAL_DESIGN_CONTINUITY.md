# Visual Design Continuity

New Learn, class, assignment, student, and analytics surfaces must extend the existing Xplore visual system.

Before designing new pages, inspect and reuse:
- layout/app shell
- spacing scale
- typography
- card/border/radius treatment
- button/input patterns
- navigation
- responsive breakpoints
- status/empty/loading/error patterns
- existing icon system
- existing interaction affordances

Do not introduce a separate design system merely because the domain is new.

## Student lesson presentation

Desktop/tablet default:
```text
Lesson title + progress

[ Discover ] [ Learn ] [ Try ] [ Practice ] [ Check ]
      ✓          ✓        ●         ○          ○

Current section content
...
Continue →
```

Phone:
- compact current-stage header or horizontally scrollable stage rail
- previous/current/next navigation
- same section model

Young learners:
- same section model
- simplified labels/progress markers
- large tap targets
- narration-ready capability
