# Print Realization

## Target

```text
verified SharedLessonDocument
→ ordinary nodes → Print representation
→ TaskAnchor → paper treatment
→ layout/pagination/answer surfaces
→ PrintDocument
→ PDF
```

Print owns paper treatments, response areas, page geometry, pagination, page breaks, answer key and export.

Print does not own ordinary composition/writing, section titles, pedagogical continuity or task semantics.

Preserve shared heading hierarchy rather than collapsing headings into generic prose.

Human answer keys use human numbering/labels; raw task IDs are metadata only.

Required figure failure cannot yield a truthful fully-ready result.

## Cutover

Prove SharedDocument Print preview/editor/PDF, then zero-call and delete independent composition/writing/Teaching Plan reinterpretation plus obsolete tests/prompts.
