# A04 — Complete Learn content and interaction authoring
Dependencies: A02

## Proposal and implementation scope
Execute content and interaction work orders before ordered assembly. Replace brief-copying and generic body fallback with proper content schema-driven writing. Replace arbitrary interaction writers. Core scope: Choice, MultiSelect, FillBlank, Numeric, ShortResponse, MatchPairs, Classify and Sequence, using repository IDs. Audit every currently production-selectable content capability and complete its native authoring route; do not quietly disable previously promised content to shrink scope. Spatial/new asset interactions remain unavailable unless independently complete. Verify editor, renderer, evaluator and publishing consume the same validated contracts. Any temporary hosting remap must preserve component identity semantics and actual interaction rendering; remove obsolete remaps only with tests.

## Acceptance gates
- **A04-G01**: Normal native Learn production invokes real content authoring; planning briefs are not final lesson payloads.
- **A04-G02**: All eight core interactions support faithful approved conversion where compatible and configured provider generation where declared.
- **A04-G03**: Known-answer regression cases pass; malformed/missing approved keys fail; no positional, number-extraction or last-word guesses remain.
- **A04-G04**: Each core payload validates, renders in its actual component and evaluates expected answers; teacher-review remains unscored pending review.
- **A04-G05**: Assembly performs no authoring and rejects missing, mismatched or unvalidated results instead of synthesizing content.
- **A04-G06**: Content-specific schemas are respected, repeated content/activity ordering survives, and Builder edits preserve valid contracts.
