# Xplore V2 `1.0.0-beta.1`

This is the production-beta snapshot for the complete destination-first unit workflow. It includes
Phases 6–13: path preparation, the unit workspace, schedules and groups, controlled shapes,
deterministic resource projections, lesson outcomes, compatibility, and beta operations.

Authoritative operational and interface documents:

- `RUNBOOK.md`
- `docs/project/XPLORE_V2_BETA_API.md`
- `handoff/XPLORE_V2_BETA_HANDOFF.md`
- `handoff/PHASE6_13_BUILD_PLAN.md`

Release acceptance requires one complete generated lesson and PDF. The user will run the broader
approximately 30-lesson human comparison after deployment; it is intentionally not a beta release
gate. That study can tune versioned classifier, skeleton, prompt, toggle, and UI behavior without
changing the beta's safety and data ownership architecture.
