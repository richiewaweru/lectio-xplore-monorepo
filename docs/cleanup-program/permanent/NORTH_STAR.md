# North Star

The **Unit path is the only supported lesson creation path**.

```text
Unit → Concepts → PathLesson → approved instructional meaning
                         ├→ PRINT → page planning/writers → @lectio/page → PDF
                         └→ LEARN → component generation → Builder → Preview → LearnRelease
                                                   → Runtime / Distribution / Insight
```

Anything detached from this graph is deletion-eligible unless required for infrastructure, build/deploy, migration history, package exports, current tests/fixtures, or authoritative documentation.
